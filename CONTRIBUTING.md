# Contributing

Use an isolated Chrome profile and a disposable unpublished draft for changes to site automation. Do not publish or accept website terms without explicit authorization.

Keep permissions narrow, preserve duplicate prevention and uncertain-publication holds, and never fabricate selectors. Re-record controls from the actual editor when the DOM changes. Do not implement anti-bot/CAPTCHA bypasses.

Report the concrete issue, expected behavior and a redacted error. Do not include private artwork, metadata exports, account information or authentication data. Run tests only when authorized; state clearly which checks were and were not performed.

Increment manifest/package versions for delivered releases and preserve numbered archives. Use the allowlisted packaging scripts. Private diagnostics, source collections, research configuration and local spreadsheet artifacts are not release assets.
